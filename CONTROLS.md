The following are my personal TSW bindings, using the **1-based button numbering from the MOZA website**.

| MOZA button | Binding |
|---:|---|
| 19 | Park |
| 20 | Horn |
| 21 | Activate |
| 22 | Next Camera |
| 22 HOLD | Interior Camera |
| 23 | Map |
| 23 HOLD | Hazards |
| 24 | Zoom Interior Camera |
| 25 | Detach Trailer |
| 32 | F7 Menu |
| 33 | Differential Lock |
| 34 | Photo Mode |
| 35 | Reset Camera |
| 36 | Menu |
| 36 HOLD | Quick Info |
| 37 | Enable/Disable Head Tracking |
| 38 | Enable/Disable Steering Camera Rotation |
| 45 | Wiper Down |
| 46 | Wiper Up |
| 47 | Zoom Out Navigation |
| 48 | Zoom In Navigation |

### Analog stick bindings

| Control | Binding |
|---|---|
| Left Stick Up/Down | Left Window |
| Right Stick Up/Down | Right Window |

The MOZA stalks are mapped as `joy4` in the supplied configuration. Your device index may differ depending on your connected peripherals.

## Notes

- These files reflect my personal control preferences.
- The TSW bindings are opinionated and may need adjustment to suit your setup.
- The Windows and Linux configurations differ primarily in how indicator inputs are handled.
